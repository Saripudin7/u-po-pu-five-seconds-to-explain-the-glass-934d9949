# Five Seconds to Explain the Glass

One original cat's defence (108 characters, a single sentence) for the
make.fun bounty
[u-po-pu-five-seconds-to-explain-the-glass-934d9949](https://make.fun/bounty/u-po-pu-five-seconds-to-explain-the-glass-934d9949):
a house cat explains, five seconds after sweeping a glass off the table,
why the glass had it coming — it was a spy for the dog.

## How to run

```sh
python3 main.py
```

Writes the sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
Python standard library only, no network access, deterministic output.
